# IMDb Top 250 Movies Analysis

## Project Overview

This project analyzes IMDb Top 250 movie data using Microsoft Power BI.

The dashboard provides insights into movie ratings, movie views, release years, and movie duration.

## Objectives

- Analyze IMDb movie ratings
- Identify the highest-rated movies
- Understand the distribution of movies by rating
- Analyze the number of movies released by year
- Analyze movies by duration
- Present the findings through an interactive Power BI dashboard

## Data Source

The movie data was collected directly from the IMDb website and imported into Power BI for analysis.

## Tools & Technologies

- Microsoft Power BI
- Data Visualization
- Power BI Data Transformation

## Dashboard

The dashboard includes:

- Total number of movies
- Average IMDb rating
- Maximum movie rating
- Number of movies with views
- Top 10 highest-rated movies
- Number of movies by rating
- Movie details with ratings and views
- Average IMDb rating
- Number of movies by year
- Number of movies by duration

## Key Insights

- The dataset contains 250 movies.
- The average IMDb rating is 8.31.
- The highest rating in the dataset is 9.30.
- The dashboard shows the distribution of movies across different ratings.
- The dashboard also provides insights into movie release years and duration.
